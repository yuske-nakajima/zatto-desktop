デスクのHTMLに、ひとつの居場所を

HTMLファイルを、ひとつの場所に。

zattoは、ローカルHTMLを1つの画面で開くビューアーです。 いくつものページを、ブラウザータブへ散らさず見比べられます。

ソースを見る 各OSの状況を見る ↓
HTML × 必要なだけ

01

ファイルは元の場所に

フォルダーから、集中できる画面へ

  1. 01

    HTMLファイルを選ぶ

    メニューから、1つまたは複数の.htmlと.htmを選択します。

  2. 02

    どこにでもドロップ

    表示中のページを含むウィンドウ全体で、ドラッグ＆ドロップできます。

  3. 03

    ページを行き来する

    1つのパネルから表示を切り替えても、相対パスの画像やスタイルは保たれます。

入口は2つ、道具は1つ

CLIとデスクトップは、同じzattoです。

ターミナルから作業を始めるならCLIを使えます。 ファイル選択やドロップから始めるなら、デスクトップアプリが自然です。

macOS · Windows · Linux

デスクトップ版のダウンロードを準備しています。

公開済みのGitHub Releaseはまだありません。 最初の公開ビルド以降は、GitHub Releasesを正式な配布先にします。

公開後の配布先を見る ↗

macOS

ダウンロード準備中

公開後はZIPを展開し、zattoをApplicationsへ移動してFinderから開きます。

Windows

ダウンロード準備中

公開後はインストーラーを実行し、スタートメニューからzattoを起動します。

Linux

ダウンロード準備中

公開後はAPTでDebianパッケージをインストールし、zattoを起動します。

開発検証用のartifact

CIでは、Windows版とLinux版のartifactを開発検証用に生成しています。 正式なダウンロードではなく、取得にはGitHubへのサインインが必要です。
